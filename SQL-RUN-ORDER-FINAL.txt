===========================================================
4. HOW DAILY EARNING WORKS
===========================================================

Each approved investment is processed independently.

Daily return period:
    principal × return_percent / 100

Weekly return period:
    principal × return_percent / 100 / 7

Monthly return period:
    principal × return_percent / 100 / 30

Example:
    ₹2,000 × 10% ÷ 7 = ₹28.57/day
    ₹3,000 × 10% ÷ 7 = ₹42.86/day

The word weekly/monthly describes the RETURN RATE PERIOD.
Wallet credit itself is DAILY.

===========================================================
5. MULTIPLE PLANS
===========================================================

Every investment_transaction has its own:
- principal
- return_percent
- earning_rate_period
- earning_next_at
- earning periods

Therefore two investments of the same customer do NOT get merged.

Example:
    Investment A: ₹2,000 @ 10% weekly = ₹28.57/day
    Investment B: ₹3,000 @ 10% weekly = ₹42.86/day
    Total = ₹71.43/day

===========================================================
6. PRINCIPAL WITHDRAWAL
===========================================================

An approved principal withdrawal reduces principal_remaining for THAT
investment only.

Future earnings are calculated using the remaining principal for that
investment. Other investments of the same customer remain independent.

Do not manually edit principal_remaining in production. Use the application's
principal withdrawal request/approval flow.

===========================================================
7. AUTOMATIC RUNNER
===========================================================

pg_cron runs the processor every 5 minutes.

It does NOT mean money is credited every 5 minutes.
The processor only creates an earning when an investment's earning_next_at
is due.

Duplicate protection prevents the same investment/period from being credited
twice.
